# For You — From Nitin

A simple, romantic single-page website.

## Add her pictures
Put your pictures inside `assets/` and name them:
- photo-1.jpg
- photo-2.jpg
- photo-3.jpg

Then open `index.html` in a browser.

## Customize
Search `index.html` for:
- Nitin
- your text
- photo-1.jpg / photo-2.jpg / photo-3.jpg

You can replace the wording with personal memories or inside jokes.
